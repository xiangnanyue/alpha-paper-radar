#### 3) VestigeKV: The NoPE-MLA KV Cache Carries Its Own Eviction Signal in a Vestigial Branch WenJie Fan
- Hotness: **284** (delta: **+0**)
- Published: 2026-09-03
- BAAI: https://hub.baai.ac.cn/paper/b70536ab-0c39-4f5c-9008-37625c277d15
- Summary: 问题所在：长生命周期的键值（KV）缓存必须在后续将要读取它的查询出现之前即完成压缩；而基于已观测注意力机制进行缓存选择的方法（如 H2O、SnapKV）在此场景下完全失效（在无位置编码（NoPE）的多头线性注意力（MLA）模型上，“针在 haystack 中”检索任务的准确率仅为 0.00–0.33），原因在于此时某 token 的重要性尚未被实际观察到。 方法设计：在 Kimi Linear 模型上，VestigeKV 利用缓存自身已携带的、与查询无关的信号进行逐行淘汰——即 64 维解耦分支（decoupled branch）。该分支本是 RoPE 旋转位置编码遗留下来的结构，在 NoPE 训练过程中被重新赋予功能，转化为一种表征 token 显著性（salience）的专用通道。该方法仅读取每行 KV 缓存中 11% 的数据，据此对缓存进行划分：得分最高的前 m 行保留在“活跃访问层”（attended tier）；其余所有行则被精确迁移（而非删除）至一个驻留于 GPU 显存中的归档区（archive），该归档区可在每个推理步中通过经验证的触发机制即时访问。整个过程无需额外训练、无需量化、亦不修改任何模型权重或内核实现。 开销表现：性能损耗可忽略不计——在上下文长度从 8K 扩展至 65K 的条件下，当缓存压缩比达 8 倍时，检索准确率仍稳定保持在 1.00；压缩比达 32 倍时，准确率仍高达 0.92；与全行保留策略相比，二者之间不存在任何性能差距。在 32 倍压缩比下，“活跃访问层”仅占 Kimi Linear 每 token 总缓存大小（8.1 KB）中的 0.25 KB；归档区则以比特级精确（bit-exact）方式完整保留在 GPU 显存中；若需释放显存，亦可选择将归档区卸载至主机内存（host offload），作为显存回收的一种变体方案。“召回层”（recall tier）——即本文默认采用的标准配置——可在 128 倍压缩比下维持 1.00 的检索准确率。 模型适配性说明：据公开报道，Kimi K3 模型采用了一种 NoPE 架构下的门控式多头线性注意力（Gated-MLA）变体；若其 KV 缓存布局与 Kimi Linear 一致，则本方法理论上可直接迁移应用；但本文所有结论均严格限定于所实测的模型，不对此作任何外推断言。 NoPE 独占性验证：同一操作若直接应用于 RoPE 架构的 MLA 模型，性能将急剧退化至 0.08（而仅做朴素淘汰的基线方法尚有 0.42）；事实上，“与查询无关的显著性信号”本身仅在无旋转编码（即 NoPE）条件下才存在——在 NoPE 下，各层 top-1 显著 token 目标覆盖全部 token 的 2.3%–6.7%，而在 RoPE 下该比例则大幅跃升至 10.2%–46.8%；更进一步，理论可证：在 RoPE 架构下，根本不存在适用于所有查询的、可精确合并的通用缓存策略（query-universal exact merging）。所有阈值均在接触实验数据前即已冻结；全文附带 20 条归档决策记录及 8 条已关闭的技术路径说明。

- Summary: 状态—预测分离（SPS）通过将前向传播拆分为“状态流”和“预测流”，使语言模型的隐状态摆脱了两大相互冲突的任务负担——既要总结上下文，又要预测下一个词元。这种分离确实有效，但开销高昂：预测流需对整个主干网络再执行一遍前向计算，导致预训练所需的浮点运算量（FLOPs）增加约1.9倍；若采用灵活的注意力掩码，实际运行时间（wall-clock time）的开销甚至更高。本文提出一种近乎零成本的实现方案，将状态—预测分离推向极致：引入一个“免费暂停词元”（free pause token），即一种完全不写入任何键（key）或值（value）的预测流，从而直接复用序列中已有的位置编码。在参数量为10亿（1B）的标准Transformer模型上，该方法在实践中将下一词元预测性能提升了2–3 centinats（百进制对数单位）；更重要的是，它在推理阶段完全不增加额外开销——既不延长上下文长度、也不扩大KV缓存、不增加解码步数，且几乎不引入任何延迟；其推理阶段FLOPs的微小增长通常可忽略不计，因为此时FLOPs并非吞吐量的瓶颈。 因此，全部开销仅存在于训练阶段。为此，我们采用四种机制协同降低训练成本：（1）采用双遍次拆分策略，在保持FlashAttention内核高效可用的前提下实现分离；（2）采用宽度为零（$w{=}0$）的预测窗口，即仅对当前词元进行预测，避免跨位置冗余计算；（3）设计共享门控前馈网络（shared gated FFN），每个位置仅执行一次FFN计算，而非为每条流各执行一次；（4）将分离操作逐步“相位化”（phasing）至序列处理流程的尾部，以进一步摊薄开销。上述技术组合使该方法相对于高度优化的预训练流水线，仅带来1.33倍的实测运行时间开销，同时恢复了SPS约94%的性能增益；而在兼顾质量与计算成本的平滑权衡曲线上，其开销甚至可进一步压低至仅1.09倍。此外，FFN优化还直接降低了推理阶段所需的原始FLOPs。最终结果是：在保持相同FLOPs、相同参数量、相同训练词元数（isoflop, isoparameter, isotoken）的前提下，本方法显著优于标准的下一词元预测式训练Transformer模型。
