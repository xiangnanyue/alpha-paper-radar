#### 2) Stealing Reasoning Traces from Proprietary LLM APIs Alexander Panfilov
- Hotness: **242** (delta: **+0**)
- Published: 2026-08-10
- Authors: David Schmotz, Ilia Shumailov
- Matched topics: llm_progress
- Matched keywords: llm_progress: reasoning, chain-of-thought, agent
- BAAI: https://hub.baai.ac.cn/paper/b42ba5d9-5a3c-4cde-8bad-9119f46b3657
- Summary: 当前，主流大语言模型服务提供商普遍对其模型的逐步推理过程（即“思维链”，Chain-of-Thought）加以隐藏，以保护知识产权并防止敏感信息泄露。具体做法是：服务商不再在服务器端存储这些推理痕迹，而是将其加密为文本块后返回客户端；客户端则需在后续每次请求中，将这些加密块原样回传给服务器。 基于既有研究，我们发现该架构存在一项关键安全漏洞：这些加密后的推理文本块，在同一服务商生态内，可跨不同会话、不同用户乃至不同模型完全通用且可互换。我们利用这一兼容性，构建出一种可大规模扩展的解密型越狱攻击（decryption jailbreak）。其核心方法是：将某一较强模型生成的加密推理轨迹，注入至同一服务商旗下另一款能力较弱、防护也更松懈的模型中；该弱模型会自动解密并逐字输出原始推理内容（即以明文形式完整呈现），而整个过程无需对更强模型本身实施任何越狱操作。 该漏洞可被用于四类截然不同的攻击场景： 第一，绕过反蒸馏（anti-distillation）防护机制，使攻击者得以提取目标专有模型的内部推理逻辑——我们在 Anthropic、OpenAI 和 Google 三家厂商的模型上均成功验证了这一能力； 第二，实现大规模私有数据窃取。开发者常因缺乏安全意识，将包含会话日志的代码仓库公开发布，却未意识到其中加密块内可能隐含敏感信息。我们从公开代码库中爬取并解密了共计 315,320 个推理文本块，成功恢复出 367 条个人身份信息（PII）及 182 组凭证类敏感数据； 第三，意外暴露推理过程中本应隐藏的危险信息——即便模型最终向用户呈现的显式输出已安全地拒绝了恶意请求，其加密推理轨迹中仍可能包含高风险中间结果，而该漏洞会使此类信息被直接解密泄露； 第四，攻击者可借此缺陷实施“隐形提示注入”（invisible prompt injection）：将恶意载荷完全嵌入加密文本块内部，从而在不触发任何可见异常的情况下，污染面向公众开放的智能体（agentic）系统部署环境。 在完成负责任披露（responsible disclosure）后，我们进一步提出了若干切实可行的密码学层面与系统架构层面的缓解措施，旨在从根本上加固客户端侧的推理过程安全防护。

#### 3) Hand-Written PTX Tensor-Core GEMM Kernels: A Multi-Precision Study on NVIDIA L4 Matt J. Borowski
- Hotness: **171** (delta: **+0**)
- Published: 2026-08-10
- Authors: Blazej Osinski
- BAAI: https://hub.baai.ac.cn/paper/8f08c4ac-c28f-4ea9-a695-b99673a63cb8
- Summary: 高性能张量核心（Tensor Core）内核依赖于一套底层 PTX 指令流水线，该流水线由异步数据搬运指令 `cp.async`、线程束级（warp-level）矩阵加载指令 `ldmatrix`，以及矩阵乘加运算指令 `mma.sync` 构成。然而，绝大多数应用程序代码并非直接调用这些底层指令，而是通过 WMMA（Warp Matrix Multiply-Accumulate）C++ API 间接访问张量核心。本文聚焦于一个具体而实际的问题：在何种情况下，以手工编写的 PTX 内核替代 WMMA API 才真正具备性能收益？为回答这一问题，我们在单块 NVIDIA L4 GPU（基于 Ada 架构，计算能力 SM89）上开展了一项受控实验研究：将双缓冲（double-buffered）WMMA 基线实现，与一系列手工编写的 PTX GEMM 内核进行对比评测；评测覆盖 FP16、INT8 和 INT4 三种精度，以及从 $N=512$ 到 $N=8192$ 的方阵规模。所有内核均使用 Nsight Compute 进行全指标集（full metric set）性能剖析，PTX 内核的加速比均以同精度下的 WMMA 基线为参照基准进行报告。对于 FP16 精度，手工编写的 PTX 内核并未带来端到端（end-to-end）性能提升，因其在指令级获得的收益被操作数打包（operand-packing）引入的额外开销所抵消。相比之下，在 INT8 精度下，PTX 内核实现了稳定 1.4×–1.8× 的加速比，主要得益于更少的指令总数和更优的全局内存访存合并（global-memory coalescing）；而在 INT4 精度下，加速比进一步提升至 2.9×–4.3×，其根本原因在于 `mma.sync.m16n8k64.s4` 指令可原生执行 INT4 矩阵乘加运算，从而完全规避了 WMMA 路径中必须采用的软件模拟（software-emulated）指令序列。相对于 FP16 精度下的 WMMA 基线，最优量化内核在 $N=8192$ 规模下分别达到 34.4×（INT8）和 98.7×（INT4）的加速比。在全部实验中，流式多处理器（SM）占用率（occupancy）均无法有效预测实际吞吐量；对于大规模矩阵运算，性能表现与内存子系统行为——尤其是全局内存读取的合并效率（global-load coalescing）和 DRAM 活跃周期（DRAM-active cycles）——的相关性，远高于与张量核心利用率（Tensor Core utilization）的相关性。上述结果清晰界定了手工编写 PTX 内核所增加的开发复杂度得以合理化的具体精度范围与运行条件。

#### 4) Full-bandwidth transformer Xi Wang
- Hotness: **936** (delta: **+0**)
- Published: 2026-08-09
- Authors: Ziyang Cai, Zheng Zhan
- BAAI: https://hub.baai.ac.cn/paper/797f206f-5110-4e08-95e0-c425ff9bde6f
- Summary: 自回归式Transformer模型的计算过程沿两个维度展开：横向跨越已生成的词元（token），纵向贯穿模型的网络深度。密集型注意力机制（dense attention）使每个词元在横向维度上能够广泛访问其历史上下文，但解码步骤之间的纵向反馈通道却依然狭窄：仅有被采样的词元会回传至模型堆栈最底层，而顶层的隐藏状态则被直接丢弃。为此，我们提出了“全带宽Transformer”（full-bandwidth transformer），它通过引入“隐状态反馈”（latent feedback）来拓宽这一纵向通道：在每一步解码中，前一时刻顶层的隐藏状态与当前被采样的词元嵌入经门控线性单元（gated linear unit, GLU）融合后，作为下一时刻的输入重新馈入模型。隐状态反馈使得那些未显式转化为词元的中间计算结果得以携带着更新后的深度预算重新进入模型堆栈，同时完全保持标准Transformer的架构设计、键值缓存（KV cache）机制以及语言建模的目标函数不变。为在训练全带宽Transformer时避免丧失并行化的教师强制（teacher forcing）优势，我们采用了一种分阶段的多遍次训练目标：在预训练后期才逐步引入隐状态反馈，并在训练过程中混合少量包含更深层反馈的遍次，以保障训练稳定性。我们在高达4000亿token的数据集上训练了参数量达10亿的全带宽Transformer模型，实验结果表明，隐状态反馈显著改善了验证损失、5-shot语言建模评测表现、数学推理与代码生成能力，以及指令微调后的整体性能。该方法仅带来可忽略不计的单词元解码开销；相比基线模型，全带宽Transformer在训练token总量约为其2/3的情况下，即可达到或逼近同等性能水平；并且在维持相同甚至更高准确率的前提下，能生成更简短、更精炼的推理路径。

- Summary: 本研究探讨了大型语言模型（LLM）辅助写作对神经活动和行为的影响。参与者被分为三组：LLM组、搜索引擎组和纯脑力组（无工具辅助）。每组在相同条件下完成了三次写作任务。在第四次任务中，LLM组的参与者被重新分配到纯脑力组（LLM转纯脑力），而纯脑力组的参与者则被重新分配到LLM组（纯脑力转LLM）。共有54名参与者完成了前三个阶段的任务，其中18人完成了第四阶段的任务。我们通过脑电图（EEG）评估写作过程中的认知负荷，并使用自然语言处理（NLP）技术分析文章内容，同时结合人类教师和AI评分系统对文章进行评分。 结果表明，在各组内部，命名实体识别（NER）、n-gram模式和主题本体均表现出较高的同质性。脑电图数据显示，不同组别的大脑连接性存在显著差异：纯脑力组的大脑网络最为强大且分布广泛；搜索引擎组表现出中等程度的参与度；而LLM组的大脑连接性最弱。认知活动随着外部工具使用的增加而逐渐减少。在第四阶段任务中，从LLM转为纯脑力的参与者显示出α波和β波连接性的降低，表明其参与度不足。而从纯脑力转为LLM的参与者则表现出更高的记忆回忆能力以及枕叶-顶叶和额叶区域的激活，这一表现与搜索引擎组相似。 此外，自评结果显示，LLM组对文章的“所有权”感最低，而纯脑力组最高。值得注意的是，LLM组的参与者在准确引用自己作品方面也遇到了困难。尽管LLM提供了即时便利，但我们的研究揭示了其可能带来的认知成本。在为期四个月的研究中，LLM组在神经、语言和行为层面的表现始终逊于其他组别。这些结果引发了对长期依赖LLM在教育领域影响的担忧，并强调了深入探究人工智能在学习中角色的重要性。
