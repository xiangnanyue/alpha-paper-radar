## 一、总体观察

- **Agent 仍是本期最强主线。** 从 `MUSE-Autoskill`、`Autodata`、`Agent-R1`、`AgentRL`、`AgentGym-RL`、`The Hitchhiker's Guide to Agentic AI` 到 `Scaling the Horizon, Not the Parameters`，论文焦点从“单次工具调用”推进到长期任务、技能管理、可观测运行时、多轮 RL、合成数据生产和软件范式重构。
- **LLM 后训练继续向“可验证推理 + on-policy 蒸馏 + 小模型推理”集中。** `The Art of Scaling Reinforcement Learning Compute for LLMs`、`Scaling Behaviors of LLM Reinforcement Learning Post-Training`、`VibeThinker-3B`、`MOPD`、`DOPD`、`RLCSD` 等论文共同说明，后训练的核心问题已从“能否 RL”转向“如何稳定扩展、如何复用教师能力、如何避免自蒸馏退化”。
- **世界模型与潜变量学习显著升温。** `Learn from your own latents and not from tokens`、`AdaJEPA`、`SkyJEPA`、`Next-Latent Prediction Transformers`、`Looped World Models`、`Neural Fields as World Models` 等论文显示，研究者正在把表示学习、控制、机器人和长程规划连接到统一的 latent/world-model 框架中。
- **效率方向从单点压缩扩展到架构、注意力、数值精度和训练动力学。** 本期反复出现 `MiniMax Sparse Attention`、`PV-Tuning`、`Rethinking Shrinkage Bias in LLM FP4 Pretraining`、`Variable-Width Transformers`、`Tapered Language Models`、`EmuGEMM`、`Smooth Scaling Laws Hide Stepwise Token Learning` 等工作，表明效率优化已经覆盖预训练、推理、矩阵核、低精度和模型形状设计。
- **多模态与生成模型继续沿“可控生成 + 3D/视频/图像编辑 + 理论化”推进。** `OmniGen2`、`Qwen-Image-2.0-RL`、`SpheRoPE`、`ChordEdit`、`SVGDreamer`、`GenRecon`、`A Mathematical Introduction to Diffusion Models` 等论文覆盖文本到图像、全景生成、SVG、3D 重建和扩散模型数学基础。
- **金融、法律、医疗、认知辅助等应用论文数量不如 Agent/LLM 多，但出现了更明确的垂直落地方向。** 例如 `MoMoE` 聚焦金融情绪，`Freeing the Law with LOCUS` 构建美国地方法规语料，`Language-Based Digital Twins for Elderly Cognitive Assistance` 面向老年认知辅助。

## 二、按主题分类总结

### 1) Agent 系统、长期任务与软件范式

**代表论文**

- `Autodata: An agentic data scientist to create high quality synthetic data`
- `MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation`
- `The Hitchhiker's Guide to Agentic AI: From Foundations to Systems`
- `Agent-R1: Training Powerful LLM Agents with End-to-End Reinforcement Learning`
- `AgentRL: Scaling Agentic Reinforcement Learning with a Multi-Turn, Multi-Task Framework`
- `AgentGym-RL: Training LLM Agents for Long-Horizon Decision Making through Multi-Turn Reinforcement Learning`
- `Scaling the Horizon, Not the Parameters: Reaching Trillion-Parameter Performance with a 35B Agent`
- `OxyGent: Making Multi-Agent Systems Modular, Observable, and Evolvable via Oxy Abstraction`
- `Memory in the Age of AI Agents`
- `Agentic Software` / `The End of Software Engineering`

**综合判断**

Agent 方向的重点已经从“让模型会调用工具”升级为系统工程问题：如何定义技能资产，如何维护长期记忆，如何把多轮交互转化为可训练轨迹，如何将合成数据生产、检索、评测和代码执行纳入可观测框架。`Autodata` 的高频出现尤其值得注意，它代表了“agentic data scientist”路线：让智能体不只是消费数据，而是主动构造、筛选和改进训练/评测数据。

**建议跟踪**

- 优先读多轮 RL、长期任务、技能/记忆管理和 agent observability 论文。
- 对工程团队而言，短期最可落地的是：任务轨迹记录、工具调用失败归因、agent 产物单元测试、技能库版本化。

### 2) LLM 后训练、推理与蒸馏

**代表论文**

- `The Art of Scaling Reinforcement Learning Compute for LLMs`
- `Scaling Behaviors of LLM Reinforcement Learning Post-Training`
- `VibeThinker-3B: Exploring the Frontier of Verifiable Reasoning in Small Language Models`
- `MOPD: Multi-Teacher On-Policy Distillation for Capability Integration in LLM Post-Training`
- `DOPD: Dual On-policy Distillation`
- `RLCSD: Reinforcement Learning with Contrastive On-Policy Self-Distillation`
- `Why Does Self-Distillation (Sometimes) Degrade the Reasoning Capability of LLMs?`
- `How Does Reasoning Flow? Tracing Attention-Induced Information Flow for Targeted RL in LLMs`
- `DeepSeekMath`、`DeepSeek-Coder`、`DeepSeekMoE`、`DeepSeek LLM`

**综合判断**

本期后训练论文形成了三条互补路线：第一是 RL compute scaling，强调可预测扩展和训练配方；第二是 on-policy / self-distillation，关注如何把教师或模型自身的强轨迹转化为稳定训练信号；第三是可解释推理流，试图定位推理能力来自哪些层、注意力路径或训练阶段。`VibeThinker-3B` 的反复出现说明小模型可验证推理仍是热点：研究者希望用更小参数规模获得可校验、可部署的推理能力。

**风险与注意点**

- 自蒸馏并非总是收益，可能削弱探索性或让模型固化错误推理模式。
- 后训练论文的 benchmark 增益需要结合 compute、数据重复使用、验证器质量和采样策略一起看。

### 3) 潜变量、世界模型与机器人控制

**代表论文**

- `Learn from your own latents and not from tokens: A sample-complexity theory`
- `AdaJEPA: An Adaptive Latent World Model`
- `SkyJEPA: Learning Long-Horizon World Models for Zero-Shot Sim-to-Real Control of Quadrotors`
- `Next-Latent Prediction Transformers Learn Compact World Models`
- `Looped World Models`
- `Neural Fields as World Models`
- `Humanoid-Gym: Reinforcement Learning for Humanoid Robot with Zero-Shot Sim2Real Transfer`
- `Do as I Do: Dexterous Manipulation Data from Everyday Human Videos`
- `SimFoundry: Modular and Automated Scene Generation for Policy Learning and Evaluation`
- `Human Universal Grasping`

**综合判断**

这一组论文显示，世界模型正在从语言模型内部推理扩展到物理控制、机器人和仿真生成。核心共识是：直接预测 token 或像素并不总是最高效，学习稳定、可组合的 latent dynamics 才可能支持长程规划和 sim-to-real。JEPA 系列、looped transformer 和 latent dynamics 论文共同强调“内部状态演化”而非单步输出。

**建议跟踪**

- 对机器人/控制方向，重点看 zero-shot sim-to-real、场景生成和人类视频数据转动作策略。
- 对 LLM/多模态方向，重点看 latent prediction 是否能减少样本复杂度和推理 token 成本。

### 4) 高效架构、低精度与训练动力学

**代表论文**

- `MiniMax Sparse Attention`
- `Efficient On-Device Diffusion LLM Inference with Mobile NPU`
- `Rethinking Shrinkage Bias in LLM FP4 Pretraining: Geometric Origin, Systemic Impact, and UFP4 Recipe`
- `PV-Tuning: Beyond Straight-Through Estimation for Extreme LLM Compression`
- `Variable-Width Transformers`
- `Tapered Language Models`
- `HydraHead: From Head-Level Functional Heterogeneity to Specialized Attention Hybridization`
- `EmuGEMM: Fused Tensor Core Kernels for Precision Emulation in Matrix Multiplication`
- `Improving Neural Network Training by Decoupling the Magnitude and Direction of Weight Vectors`
- `Smooth Scaling Laws Hide Stepwise Token Learning`

**综合判断**

效率研究不再局限于“剪枝/量化/蒸馏”单点优化，而是进入系统协同：注意力稀疏化、不同层宽度设计、head 功能异质性、低精度数值偏差、矩阵核实现和训练动力学一起影响最终成本。值得注意的是，多篇论文都在讨论“看似平滑的 scaling law 背后是否存在阶段性学习事件”，这对预训练监控和数据调度很重要。

**建议跟踪**

- 如果目标是部署，优先关注 on-device inference、稀疏注意力、FP4/UFP4 和 fused kernel。
- 如果目标是训练，优先关注权重方向/幅度解耦、token 学习阶段、宽度形状设计。

## 五、结论

2026-06-07 至 2026-07-07 的论文雷达显示，AI 研究重心正在从“单模型能力提升”转向“可训练、可部署、可审计的智能系统”。Agent 是最突出的系统化方向，后训练和蒸馏是提升推理能力的核心手段，latent/world model 则连接了语言、多模态和机器人控制。下一阶段的跟踪重点建议放在三类论文上：

1. **能给出可复现实验和系统抽象的 Agent 论文**；
2. **能解释后训练增益来源、而不只是报告 benchmark 的推理论文**；
3. **能同时说明算法收益与部署成本的效率论文**。
