# 报告论文分类总结（基于 2026-05-29 ~ 2026-06-06）

## 一、总体观察

- **主线一：LLM 后训练进入“可控推理 + 可验证优化”阶段。** 本期大量论文围绕 RL 后训练、奖励重分配、自蒸馏、测试时自改进、隐式/潜在推理、函数向量与 judge calibration 展开，重点不再只是提升 benchmark 分数，而是解释推理为何变好、何处失效、如何把改进稳定复用。
- **主线二：Agent 研究从单次任务表现转向生命周期治理。** 技能文件、记忆文件、长期状态、权限拒绝信号、工具调用、稀疏注意力服务、长程科研/工程任务等成为高频议题，说明 Agent 系统正在从“提示词工程”推进到“运行时、记忆、权限、可观测性、技能资产管理”的工程体系。
- **主线三：数据与评测的“可审计性”明显升温。** 训练数据归因、数据混合诊断、科学想法甄别、成对评测分辨率、动态临床决策、AI 文本检测、 stance simulation 审计等工作共同指向一个问题：模型能力越强，越需要知道数据从哪里来、评测是否真的测到了能力、模拟输出是否可靠。
- **主线四：效率路线从模型压缩扩展到推理、注意力、优化器和架构共设计。** 本期出现替换式 LLM 压缩、跨层 sparse attention、agent serving、短卷积增强 Transformer、QKV 投影共享、Muon 谱缩放规律等工作，核心是以更少显存、token 或训练迭代获得接近前沿模型的能力。
- **主线五：量化金融论文数量不多，但集中在组合构建、状态切换与不确定性建模。** 本期量化方向更重视“预测—配置—风险—市场冲击”的闭环：从 Black-Litterman / DPO / anticipatory portfolio 到 HMM-RL、MS-GARCH、概率校准和结构突变检测，均强调在非平稳市场中将模型输出转化为稳健配置。

## 二、按主题分类摘要

### 1) Agent 系统、技能生命周期与运行时基础设施

**代表问题**

- Agent 如何在长程任务中维护可复用技能、可追踪行为轨迹与稳定记忆。
- 多 Agent 或工具调用场景中，如何处理通信延迟、权限拒绝、技能投毒、上下文漂移和服务成本。
- 长期科研/工程任务是否能被 frontier models 可靠完成，失败点是规划、工具使用、验证还是上下文管理。

**关键结论（跨论文）**

- Agent 能力的瓶颈正在从“单轮回答质量”迁移到“状态管理与执行治理”：技能、memory、policy 配置文件会持续影响未来行为，因此需要版本化、审计和 trait tracking。
- 技能正在被视为长期资产，但也带来新的攻击面；`SkillHarm`、`Tracking the Behavioral Trajectories of Adapting Agents` 与 `Will the Agent Recuse Itself?` 一类工作提示，技能生命周期中的创建、修改、调用和权限边界都需要测试。
- 运行时效率开始成为 Agent 规模化前提。`Vortex`、跨层 sparse attention 与工具调用 RL 相关工作说明，生产级 Agent 不仅要会推理，还要在长上下文、高并发、多工具环境下可服务。

**代表论文**

- `MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation`
- `SkillHarm: Lifecycle-Aware Skill-Based Attacks via Automated Construction`
- `Tracking the Behavioral Trajectories of Adapting Agents`
- `Will the Agent Recuse Itself? Measuring LLM-Agent Compliance with In-Band Access-Deny Signals`
- `Streaming Communication in Multi-Agent Reasoning`
- `AutoLab: Can Frontier Models Solve Long-Horizon Auto Research and Engineering Tasks?`
- `Vortex: Efficient and Programmable Sparse Attention Serving for AI Agents`
- `On Effectiveness and Efficiency of Agentic Tool-calling and RL Training`

**阅读判断**

> Agent 方向值得优先跟踪“技能/记忆/权限/运行时”四件套。短期最可落地的是技能库测试、权限拒绝信号合规、稀疏注意力服务和长任务执行日志；中期需要把 agent 行为变化纳入 CI/评测，而不是只看最终任务成功率。

### 2) LLM 后训练、推理机制与自我改进

**代表问题**

- RL 后训练的收益如何随 compute、数据和奖励设计缩放。
- 推理改进到底来自更多 token、潜在状态计算、奖励重分配、自蒸馏还是测试时更新。
- 模型能否在不显式展开长 CoT 的情况下完成内部推理，并将推理能力迁移到新任务或小语种翻译。

**关键结论（跨论文）**

- 后训练正在从“统一奖励”走向更细粒度 credit assignment。`RREDCoT` 强调 segment-level reward redistribution，`Reinforcement Learning via Self-Distillation` 与 `Self-Trained Verification` 则说明自生成监督信号仍是提升推理的重要低成本路线。
- 潜在推理和工作记忆是减少 token 成本的重要方向。`Unlocking the Working Memory of Large Language Models for Latent Reasoning`、`Latent Reasoning with Normalizing Flows`、`Learn from your own latents and not from tokens` 都在尝试把推理从外显文本链条转向内部表征演化。
- 测试时适配继续升温，但工程瓶颈很明确：检索、样本选择、梯度缓存与每 query 更新成本决定其能否进入实时系统。

**代表论文**

- `The Art of Scaling Reinforcement Learning Compute for LLMs`
- `Scaling Behaviors of LLM Reinforcement Learning Post-Training: An Empirical Study in Mathematical Reasoning`
- `RREDCoT: Segment-Level Reward Redistribution for Reasoning Models`
- `Reinforcement Learning via Self-Distillation`
- `Self-Trained Verification for Training- and Test-Time Self-Improvement`
- `Efficient Test-Time Finetuning of LLMs via Convex Reconstruction and Gradient Caching`
- `Unlocking the Working Memory of Large Language Models for Latent Reasoning`
- `Latent Reasoning with Normalizing Flows`
- `Fast & Faithful Function Vectors`
- `Reinforcement Learning Elicits Contextual Learning of Unseen Language Translation`

**阅读判断**

> 这一组论文共同提示：下一阶段推理优化不会只靠“生成更长 CoT”，而会转向 token 外的内部计算、可验证奖励分配和测试时轻量适配。对应用团队而言，应优先记录每个问题的推理成本、验证信号、失败 trace 与可复用校验器，而不是单纯比较单次输出质量。

### 3) 数据治理、训练数据归因与评测可靠性

**代表问题**

- 能否从模型输出反推预训练数据混合，或定位哪些训练子集导致能力变化。
- 科学研究想法、临床决策、AI 文本检测、stance simulation 等复杂任务的评测是否有足够分辨率。
- 多数据源、多 benchmark 下，如何避免“看似提升，实际测不准”。

**关键结论（跨论文）**

- 模型能力审计正从黑箱评分扩展到数据层审计。`LLMSurgeon` 试图估计预训练数据域分布，`STRIDE` 用 sparse recovery 做训练数据归因，`MIRA` 关注 mid-training data selection，这些工作都说明数据配方本身正成为可诊断对象。
- 评测质量成为瓶颈。`SoundnessBench`、`ProjectionBench`、`Resolution Diagnostics for Paired LLM Evaluation` 和 `Benchmark Everything Everywhere All at Once` 都在追问 benchmark 是否真的能区分好坏研究想法、科学假设、模型差异和泛化边界。
- 医疗、社会模拟与安全场景要求更强证据链。动态临床决策、ED 自伤监测、ADHD 教师叙述挖掘、stance simulation 审计等论文共同显示，LLM 输出必须附带证据抽取、校准或失效分析。

**代表论文**

- `LLMSurgeon: Diagnosing Data Mixture of Large Language Models`
- `STRIDE: Training Data Attribution via Sparse Recovery from Subset Perturbations`
- `MIRA: Mid-training Rubric Anchoring for Source-Aware Data Selection`
- `SoundnessBench: Can Your AI Scientist Really Tell Good Research Ideas from Bad Ones?`
- `ProjectionBench: Evaluating Scientific Hypothesis Generation in LLMs Under Progressive Information Disclosure`
- `Resolution Diagnostics for Paired LLM Evaluation`
- `Benchmark Everything Everywhere All at Once`
- `Evaluating Large Language Models in Dynamic Clinical Decision-Making with Standardized Patient Cases`
- `Revising Context, Shifting Simulated Stance: Auditing LLM-Based Stance Simulation in Online Discussions`

**阅读判断**

> 对需要长期跟踪论文雷达的系统而言，评测论文的价值不应低估。后续可以把“数据来源、评测分辨率、是否有可复现实验、是否区分能力与偏见”作为每篇论文的二级标签，以便从单纯推荐转向研究质量筛选。

### 4) 高效架构、压缩、注意力与优化器

**代表问题**

- 如何在不显著牺牲性能的情况下降低 LLM/多模态模型的训练、推理和服务成本。
- Transformer 的冗余到底存在于层、子模块、投影矩阵、注意力路由还是优化器谱结构中。
- 新架构组件（短卷积、投影共享、稀疏路由、函数向量）是否能在规模化时保持收益。

**关键结论（跨论文）**

- LLM 压缩从整层删除转向子模块级替换。`From Layers to Submodules` 指出冗余不一定连续分布，也不均匀分布在 Attention 与 FFN 之间，因此更细粒度压缩更合理。
- 注意力优化正在从单层稀疏化走向跨层共享路由和服务框架。`You Only Index Once` 与 `Vortex` 代表了“减少重复索引/路由开销”的方向。
- 优化器研究出现更工程化的尺度规律。`Spectral Scaling Laws of Muon` 与 `Denoise First, Orthogonalize Later` 将 Muon 的 NS 迭代、动量谱滤波和规模扩展联系起来，对大模型训练调参有直接启发。

**代表论文**

- `From Layers to Submodules: Rethinking Granularity in Replacement-Based LLM Compression`
- `You Only Index Once: Cross-Layer Sparse Attention with Shared Routing`
- `Vortex: Efficient and Programmable Sparse Attention Serving for AI Agents`
- `Dynamic Short Convolutions Improve Transformers`
- `Do Transformers Need Three Projections? Systematic Study of QKV Variants`
- `Spectral Scaling Laws of Muon`
- `Denoise First, Orthogonalize Later: Understanding Momentum in Muon via Spectral Filtering`
- `Code2LoRA: Hypernetwork-Generated Adapters for Code Language Models under Software Evolution`
- `TailLoR: Protecting Principal Components in Parameter-Efficient Continual Learning`

**阅读判断**

> 这一类论文适合按“可直接进入工程实验”的优先级跟踪：跨层 sparse attention、子模块替换压缩、QKV 投影共享和 Muon 迭代配置最容易转化为训练/推理成本实验；潜在收益大，但需要严控不同模型规模下的退化曲线。

### 5) 多模态生成、视觉理解与机器人

**代表问题**

- 视觉生成是否能通过开放许可大数据集、统一视频模型、无需 VQ 的自回归图像生成和 diffusion steering 获得更稳健的可控性。
- VLM 能否在时间序列异常、3D 摄影规划、深度估计、机器人创造性问题求解等场景给出可信解释。
- 多模态任务中的失败模式是否来自数据、架构、评测还是物理世界约束。

**关键结论（跨论文）**

- 数据集基础设施仍是视觉生成关键瓶颈。`GPIC` 通过 permissive licensing、去重、安全过滤和大规模 captioning 试图降低视觉生成研究的合规与复现实验门槛。
- 视觉/视频生成开始强调统一建模和可控编辑。`Lumos-Nexus`、`TunerDiT`、`OmniGen/OmniGen2`、`Autoregressive Image Generation without Vector Quantization` 分别从统一 latent、training-free steering、统一图像生成与非 VQ 自回归角度推进。
- 机器人和物理场景仍暴露出“聪明但不接地气”的问题。`RoboWits`、`HANDOFF`、`DynaFLIP` 与 `RiskFlow` 表明真实世界任务需要把感知、动力学、动作约束和安全场景生成纳入闭环。

**代表论文**

- `GPIC: A Giant Permissive Image Corpus for Visual Generation`
- `Lumos-Nexus: Efficient Frequency Bridging with Homogeneous Latent Space for Video Unified Models`
- `TunerDiT: Training-free Progressive Steering of Diffusion Transformer for Multi-Event Video Generation`
- `Autoregressive Image Generation without Vector Quantization`
- `OmniGen: Unified Image Generation`
- `OmniGen2: Exploration to Advanced Multimodal Generation`
- `Modeling Depth Ambiguity: A Mixture-Density Representation for Flying-Point-Free Depth Estimation`
- `Tiny but Trusted: Efficient Vision-Language Reasoning for Time-Series Anomaly Detection`
- `RoboWits: Unexpected Challenges for Robotic Creative Problem Solving`
- `HANDOFF: Humanoid Agentic Task-Space Whole-Body Control via Distilled Complementary Teachers`

**阅读判断**

> 多模态方向的短期重点不是单一模型刷榜，而是“数据许可 + 可控生成 + 物理约束 + 可信解释”。如果要选可跟进论文，优先看 GPIC、MDA depth、Lumos-Nexus、TunerDiT 与 HANDOFF，它们分别对应数据、表示、控制和具身执行四个关键环节。

### 6) 量化金融、投资组合与时间序列

**代表问题**

- 在非平稳市场中，如何把 regime detection、分布式不确定性、市场冲击和预测校准纳入组合优化。
- 时间序列预测如何处理异方差、结构突变、高维因子和空间相关。
- 金融 LLM 是否对特定资产存在偏好，并影响投资建议。

**关键结论（跨论文）**

- 组合优化从点估计权重转向分布、状态与部署影响。`Distributional Portfolio Optimization` 统一权重/收益/参数分布；`Anticipatory Portfolio Optimization` 将信息、预测与市场冲击放进同一控制框架；传统 Black-Litterman 和约束优化仍被用作稳定配置基线。
- 状态切换模型继续强化其解释性价值。`Regime-Based Portfolio Allocation` 用 HMM-RL 做战术配置，`Multi-Scale Markov Switching GARCH` 将 daily / 4h / hourly 波动状态组合成跨尺度 regime tensor，说明多频 regime 对风险管理更有信息量。
- 风险预测越来越重视校准。`ProbRes` 关注金融异方差下的概率预测校准，结构突变检测和 sample splitting 相关论文则服务于高维时间序列中的模型稳定性检验。
- 金融 LLM 审计值得单列跟踪。`Auditing Asset-Specific Preferences in Financial Large Language Models` 说明 robo-advisor 或交易 Agent 可能带有资产偏好，需要行为审计、表示审计和决策层审计。

**代表论文**

- `From Classical Optimization to Bayesian Integration: A Comprehensive Analysis of Systematic Portfolio Management`
- `Distributional Portfolio Optimization (DPO): A Unified Framework for Distributions over Weights, Returns, and Parameters`
- `Anticipatory Portfolio Optimization`
- `Regime-Based Portfolio Allocation Using Hidden Markov Models and Reinforcement Learning`
- `Multi-Scale Markov Switching GARCH`
- `ProbRes: Probabilistic Time Series Forecasting with Residual-Driven Volatility Modeling`
- `Structural Change Detection in High-Dimensional Transformed Factor Models via Canonical Correlation Analysis`
- `Leave a Window Out: Modifying the Jackknife for Predictive Inference in Time Series`
- `Eigenvector Spatial Filters Nuclear Norm Matrix Completion with Application to Air Quality Data`
- `Auditing Asset-Specific Preferences in Financial Large Language Models: Evidence from Bitcoin Representations and Portfolio Allocation`

**阅读判断**

> 若服务于投资研究，建议优先精读 DPO、Anticipatory Portfolio Optimization、HMM-RL allocation、Multi-Scale MS-GARCH 和金融 LLM 偏好审计。它们分别覆盖组合分布建模、市场冲击/前瞻信息、状态识别、多频波动和 Agent 投顾风险，能组成一条较完整的“金融 Agent 风控”研究线。

## 三、跨主题趋势与机会

### 趋势 1：从“更强模型”转向“可治理系统”

LLM 与 Agent 论文共同显示，真实系统需要的不只是更强 base model，而是数据归因、技能生命周期、权限合规、记忆管理、运行时成本、评测分辨率和持续审计。未来值得关注的论文通常会同时给出能力提升和治理机制，而不是只报告单点 benchmark。

### 趋势 2：推理优化正在内化

潜在推理、工作记忆、function vectors、自蒸馏和 reward redistribution 都在减少对长 CoT 的依赖。这对生产系统有两层意义：一是降低 token 成本；二是外部日志不再完整暴露内部推理，需要新的可解释性与验证工具。

### 趋势 3：训练数据与评测将成为竞争壁垒

`LLMSurgeon`、`STRIDE`、`MIRA`、`SoundnessBench`、`ProjectionBench` 等论文指向同一事实：模型能力差异越来越依赖数据配方与评测设计。对论文雷达而言，后续不应只标记“模型/方法”，还应标记“数据审计/评测审计/可复现性”。

### 趋势 4：金融与 Agent 的交叉风险正在形成

金融论文强调 regime、分布、市场冲击和不确定性；Agent/LLM 审计论文强调偏好、权限、技能攻击和长期行为漂移。两者结合后，金融 Agent 的核心问题将是：模型偏好是否影响资产配置，工具调用是否越权，市场冲击是否被忽略，输出建议是否经过风险校准。

## 四、建议优先精读清单

### A. Agent / LLM 系统优先级

1. `MUSE-Autoskill`：理解技能生命周期管理如何支撑可复用 Agent。
2. `SkillHarm`：评估第三方技能与技能文件投毒风险。
3. `Tracking the Behavioral Trajectories of Adapting Agents`：用于长期 Agent 行为漂移监控。
4. `Vortex` 与 `You Only Index Once`：关注 Agent 长上下文 serving 成本。
5. `AutoLab`：评估 frontier models 在长程科研/工程任务中的真实边界。

### B. 后训练 / 推理优先级

1. `Scaling Behaviors of LLM Reinforcement Learning Post-Training`：建立 RL 后训练 scaling 直觉。
2. `RREDCoT`：理解细粒度奖励重分配。
3. `Unlocking the Working Memory of Large Language Models for Latent Reasoning`：跟踪非外显 CoT 推理。
4. `Efficient Test-Time Finetuning of LLMs`：评估测试时适配的工程可行性。
5. `Fast & Faithful Function Vectors`：关注可解释、可迁移的内部功能表示。

### C. 量化金融 / 时间序列优先级

1. `Distributional Portfolio Optimization`：作为分布式组合优化框架阅读。
2. `Anticipatory Portfolio Optimization`：重点看信息、预测与 market impact 的统一分解。
3. `Regime-Based Portfolio Allocation Using HMM and RL`：适合转化为战术配置实验。
4. `Multi-Scale Markov Switching GARCH`：适合多频波动 regime 监控。
5. `Auditing Asset-Specific Preferences in Financial LLMs`：适合作为金融 Agent 风控评测入口。

### D. 多模态 / 视觉生成优先级

1. `GPIC`：重点看许可、去重、安全过滤和 caption pipeline。
2. `Lumos-Nexus`：关注统一视频模型中的频率桥接与 latent space。
3. `TunerDiT`：关注 training-free video generation steering。
4. `Modeling Depth Ambiguity`：可落地的边界深度不确定性建模。
5. `HANDOFF`：关注 humanoid whole-body control 的 teacher distillation 方案。
