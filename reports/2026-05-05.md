## 金融量化

### 1) Large-Scale Asset Selection via Metric Dependence with Enriched High Frequency Information（2605.02326）
- **一句话结论**：把“日收益+日内风险曲线”作为对象数据做依赖筛选，较传统标量筛选更能提升大规模组合的样本外表现。
- **方法亮点**：
  - 用加权乘积度量把收益与日内风险状态联立；
  - 用 Fréchet variation dependence score 做筛选排序；
  - 给出在高维与时间依赖下的 sure screening 与一致性保证。
- **对金融量化的迁移价值**：
  - 直接可迁移到 A 股/美股分钟级选股前置流程；
  - 适合作为“优化器之前的降维闸门”，降低均值-方差法对估计误差的脆弱性。
- **Deep read / Implement**：**值得 implement（高优先级）**。

### 2) Decision-Induced Ranking Explains Prediction Inflation and Excessive Turnover in SPO-Based Portfolio Optimization（2605.01176）
- **一句话结论**：SPO 类决策学习会系统性放大收益预测并诱发高换手，需通过输出约束与组合级调仓约束做稳定化。
- **方法亮点**：
  - 基于 KKT 把投资决策解释为“风险/交易成本调整后的边际得分排序”；
  - 实证比较 clipping、min-max、partial adjustment 等稳健策略。
- **对金融量化的迁移价值**：
  - 可直接改造现有 alpha-to-weight pipeline；
  - 尤其适合高频再平衡或交易成本敏感策略。
- **Deep read / Implement**：**值得 deep read（中高优先级）**。

## 截面 / 时序模型

### 1) Estimation and Inference for the τ-Quantile of Individual Heterogeneous Coefficient（2605.01923）
- **一句话结论**：针对个体异质系数分位数给出可估计、可推断框架，补齐“平均效应之外”的尾部分布信息。
- **方法亮点**：从“个体参数分布”而非总体均值出发，支持对不同分位点做结构化统计推断。
- **对金融量化的迁移价值**：
  - 可用于横截面因子暴露异质性的尾部风险刻画；
  - 适用于“谁在极端市场下失效更快”的识别。
- **Deep read / Implement**：**值得 deep read（中优先级）**。

### 2) Simultaneous Inference for Nonlinear Time Series, a Sieve M-regression Approach（2605.02253）
- **一句话结论**：在非线性时序下做“同时推断”能避免逐点检验带来的显著性膨胀。
- **方法亮点**：Sieve M-regression + simultaneous inference，适配复杂动态结构。
- **对金融量化的迁移价值**：
  - 适合时变信号挖掘中的区间/带状不确定性控制；
  - 对策略上线前的稳健性验证有直接价值。
- **Deep read / Implement**：**值得 deep read（中优先级）**。

### 3) EstemPMM: Polynomial Maximization Method for Non-Gaussian Regression and Time Series in R（2605.02673）
- **一句话结论**：给出非高斯回归/时序估计的可执行工具链，有助于把“分布错配”问题工程化处理。
- **方法亮点**：围绕多项式极大化构建估计流程，并以 R 包形态降低复现门槛。
- **对金融量化的迁移价值**：
  - 对肥尾、偏态收益序列更友好；
  - 可作为传统高斯假设模型的 stress-test 对照组。
- **Deep read / Implement**：**值得小规模 implement（中优先级）**。

## SOTA 深度学习

### 1) Compress Then Adapt? No, Do It Together via Task-aware Union of Subspaces（2605.02829）
- **一句话结论**：压缩与适配若联合优化，可在更低参数预算下超过常规 PEFT 基线。
- **方法亮点**：
  - 用任务感知子空间并集统一压缩与微调；
  - 全局 rank 分配按“边际增益/参数成本”决策；
  - 避免“先压缩后适配”的子空间错配。
- **对金融量化的迁移价值**：
  - 对资源受限场景（研究集群/线上推理）非常关键；
  - 可用于金融文本、因子描述生成、研究助手模型的低成本落地。
- **Deep read / Implement**：**值得 deep read + implement（高优先级）**。

### 2) A decoupled diffusion planner ... cost-conditioned generation ...（2605.02777）
- **一句话结论**：把安全约束与收益优化解耦，能显著提高“满足约束下的回报”。
- **方法亮点**：
  - 成本条件引导（安全）与奖励梯度引导（性能）分离；
  - FTR 抑制“提收益却抬成本”的偏移。
- **对金融量化的迁移价值**：
  - 与组合层风险预算控制同构；
  - 可迁移到“在 VaR/回撤上限下优化收益”的策略生成框架。
- **Deep read / Implement**：**值得 deep read（中高优先级）**。

### 3) First-Order Efficiency for Probabilistic Value Estimation via A Statistical Viewpoint（2605.02782*候补替换为 2605.02827）
- **一句话结论**：统一多类 Shapley/semivalue 估计器的一阶误差结构后，可直接按 MSE 目标设计更高效估计器。
- **方法亮点**：AIPW 风格影响函数统一视角 + 一阶 MSE 显式分解 + EASE 估计器。
- **对金融量化的迁移价值**：
  - 可用于因子贡献、样本价值评估、训练数据甄别；
  - 对可解释性与数据治理有长期价值。
- **Deep read / Implement**：**值得 deep read（中优先级）**。

## 大模型 / Agent / RAG

### 1) HAAS: A Policy-Aware Framework for Adaptive Task Allocation Between Humans and AI Systems（2605.02832）
- **一句话结论**：治理不是开/关按钮，而是可调参数；适度治理在学习后期可实现效率与风险折中最优。
- **方法亮点**：规则系统先约束可行策略，再用 contextual bandit 在可行域内学习分配。
- **对金融量化的迁移价值**：
  - 可直接映射到“研究员—模型—风控”的任务编排；
  - 对交易前审批、模型上线闸门设计有参考意义。
- **Deep read / Implement**：**值得 deep read（中高优先级）**。

### 2) When Audio-Language Models Fail to Leverage Multimodal Context ...（2605.02782）
- **一句话结论**：模型并不会自动利用你给的上下文，提示增强可能几乎无效甚至退化。
- **方法亮点**：系统对比诊断标签、临床描述、混合 prompt 微调对性能的真实增益。
- **对金融量化的迁移价值**：
  - 对 RAG/Agent 具有警示：检索命中 ≠ 真实利用；
  - 需建立“上下文利用率”评测，而非只看最终回答分数。
- **Deep read / Implement**：**值得 deep read（中优先级）**。

### 3) VideoNet: A Large-Scale Dataset for Domain-Specific Action Recognition（2605.02834）
- **一句话结论**：领域专用基准仍能有效拉开模型能力差异，few-shot 并非总能补齐差距。
- **方法亮点**：1,000 动作/37 领域大规模评测 + 近 50 万训练样本构建。
- **对金融量化的迁移价值**：
  - 启发“金融专域 benchmark-first”路线；
  - 比泛化榜单更能指导本域模型选择。
- **Deep read / Implement**：**值得选读（中优先级）**。

## 今日研究趋势
1. **从“精度崇拜”转向“可部署最优”**：多篇工作直接报告约束、换手、参数预算下的最优策略，而非裸精度。
2. **从“单点最优”转向“系统协同”**：压缩与适配、治理与学习、筛选与优化都在走联合设计。
3. **从“提示工程乐观”转向“可验证利用”**：上下文提供并不等于模型吸收，评测体系需升级。

## 本周值得跟踪的问题
1. 在我们现有组合框架中，**SPO 稳定化**（clipping/partial adjustment）哪种交易成本下收益-换手比最好？
2. **高频对象化筛选（MDS）**是否在不同行业/市值层上都稳定，还是受流动性结构影响？
3. 对内部研究助手，如何定义并度量 **RAG 上下文利用率**（不是检索召回率）？
4. 是否可将 **任务约束扩散规划**思想迁移为“风险预算约束下的策略路径生成”？

## 可复现想法清单（本周可开工）
1. **MDS 轻量复现**：
   - 数据：分钟级收益+波动状态曲线；
   - 任务：先筛选再做最小方差/均值方差；
   - 指标：样本外 Sharpe、换手、最大回撤。
2. **SPO 稳定化 ablation**：
   - 对比：无约束、clipping、min-max、partial adjustment；
   - 指标：IC、PnL、换手、冲击成本后净值。
3. **上下文利用率评测器**：
   - 构建“给上下文/不给上下文”对照问答集；
   - 输出：增益分解（检索增益、推理增益、幻觉变化）。
4. **联合压缩+适配试验**：
   - 在小型金融 NLP 任务上比较 LoRA vs 联合子空间方案；
   - 指标：参数量、延迟、任务分数、稳定性。
