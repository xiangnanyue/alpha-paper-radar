- Summary: 本研究探讨了大型语言模型（LLM）辅助写作对神经活动和行为的影响。参与者被分为三组：LLM组、搜索引擎组和纯脑力组（无工具辅助）。每组在相同条件下完成了三次写作任务。在第四次任务中，LLM组的参与者被重新分配到纯脑力组（LLM转纯脑力），而纯脑力组的参与者则被重新分配到LLM组（纯脑力转LLM）。共有54名参与者完成了前三个阶段的任务，其中18人完成了第四阶段的任务。我们通过脑电图（EEG）评估写作过程中的认知负荷，并使用自然语言处理（NLP）技术分析文章内容，同时结合人类教师和AI评分系统对文章进行评分。结果表明，在各组内部，命名实体识别（NER）、n-gram模式和主题本体均表现出较高的同质性。脑电图数据显示，不同组别的大脑连接性存在显著差异：纯脑力组的大脑网络最为强大且分布广泛；搜索引擎组表现出中等程度的参与度；而LLM组的大脑连接性最弱。认知活动随着外部工具使用的增加而逐渐减少。在第四阶段任务中，从LLM转为纯脑力的参与者显示出α波和β波连接性的降低，表明其参与度不足。而从纯脑力转为LLM的参与者则表现出更高的记忆回忆能力以及枕叶-顶叶和额叶区域的激活，这一表现与搜索引擎组相似。此外，自评结果显示，LLM组对文章的“所有权”感最低，而纯脑力组最高。值得注意的是，LLM组的参与者在准确引用自己作品方面也遇到了困难。尽管LLM提供了即时便利，但我们的研究揭示了其可能带来的认知成本。在为期四个月的研究中，LLM组在神经、语言和行为层面的表现始终逊于其他组别。这些结果引发了对长期依赖LLM在教育领域影响的担忧，并强调了深入探究人工智能在学习中角色的重要性。

- Summary: 强化学习（RL）已成为现代大语言模型的关键组成部分，然而 rollout 阶段仍是 RL 训练流程中的主要性能瓶颈。尽管多词元预测（Multi-Token Prediction, MTP）通过推测性解码为加速 rollout 提供了一种天然可行的方案，但多项研究均观察到：在 RL 训练过程中，MTP 的接受率显著下降，导致其加速效果十分有限。为突破这一瓶颈，我们开展了名为 Bebop 的系统性研究，深入探究 MTP 在大语言模型后训练阶段的行为特性，并提出一套切实可行的实践方案，以将 MTP 有效集成至大规模 RL 训练管线中。 首先，我们揭示出 MTP 接受率本质上受限于模型熵值的波动——在 RL 训练阶段，随着模型熵值上升，MTP 接受率呈现出清晰的负线性相关关系。 其次，我们证明：相较于贪心式草稿采样（greedy draft sampling），基于概率的拒绝采样（probabilistic rejection sampling）能大幅缓解 RL 过程中熵值扰动对 MTP 接受率造成的不利影响。进一步分析发现，传统 MTP 训练目标（如交叉熵损失或 KL 散度损失）在此类场景下并非最优；为此，我们提出一种全新的端到端总变差（Total Variation, TV）损失函数，该损失直接以多步拒绝采样的接受率为优化目标，使 MTP 接受率提升约 10%，最高可达 95%，并在数学推理、代码生成与智能体（agentic）任务等多种场景下，额外带来最高达 25% 的推理吞吐量增益。 第三，我们在 RL 训练过程中测试了多种在线 MTP 训练策略，结果表明：若在 RL 启动前，采用端到端 TV 损失结合拒绝采样方式完成 MTP 预训练，则可在整个 RL 训练过程中保持稳定且一致的 MTP 接受率与加速效果，从而彻底避免代价高昂的在线 MTP 模型更新。我们开展了大量实验并进行了深入分析，全面验证了上述发现。实验结果表明，本方法在 Qwen3.5、Qwen3.6 和 Qwen3.7 模型的异步 RL 训练中，实现了最高达 1.8 倍的端到端训练加速。

#### 5) Code2LoRA: Hypernetwork-Generated Adapters for Code Language Models under Software Evolution
- Hotness: **180** (delta: **+0**)
- Published: 2026-06-04
- Authors: Liliana Hotsko, Yinxi Li, Yuntian Deng, Pengyu Nie
- Matched topics: llm_progress
- Matched keywords: llm_progress: rag
- BAAI: https://hub.baai.ac.cn/paper/ff7989c6-9e91-442e-87e5-0f3532a378fb
- Summary: 代码语言模型需要仓库级上下文，以解析导入语句、API 调用以及项目约定。现有方法通常将此类知识作为长输入注入（例如通过检索增强生成 RAG 或依赖关系分析），或采用按仓库微调（fine-tuning）及 LoRA 方法——但这些方案在仓库规模上成本高昂，且面对持续演进的代码库时鲁棒性差、易失效。为此，我们提出 Code2LoRA：一种超网络（hypernetwork）框架，可动态生成面向特定代码仓库的 LoRA 适配器，在推理阶段零开销（即不增加任何 token 消耗）地注入仓库专属知识。Code2LoRA 支持两种使用场景：Code2LoRA-Static 将单个仓库快照转换为一个静态适配器，适用于对结构稳定、变动较少的代码库进行理解；而 Code2LoRA-Evo 则维护一个由门控循环单元（GRU）隐状态驱动的适配器，该隐状态随每次代码变更（code diff）实时更新，因而更适用于处于活跃开发阶段、持续演进的代码库。为全面评估 Code2LoRA 相较于各类参数高效微调（PEFT）基线方法的性能，我们构建了 RepoPeftBench 基准测试集：涵盖 604 个 Python 代码仓库，包含两个评测轨道——静态轨道（static track）含 40,000 条训练样本与 12,000 条测试样本，均为断言补全（assertion-completion）任务；演化轨道（evolution track）则基于提交记录（commit）构造，含 215,000 条训练样本与 87,000 条测试样本。在静态轨道上，Code2LoRA-Static 取得了 63.8% 的跨仓库准确匹配率（cross-repo exact match）与 66.2% 的同仓库准确匹配率（in-repo exact match），成功达到按仓库独立微调 LoRA 所能实现的性能上限；在演化轨道上，Code2LoRA-Evo 实现了 60.3% 的跨仓库准确匹配率，相较仅使用单一共享 LoRA 适配器的基线方法提升了 5.2 个百分点（+5.2 pp）。Code2LoRA 的源代码托管于 https://anonymous.4open.science/r/code2lora-6857；模型检查点（checkpoints）及 RepoPeftBench 数据集则发布于 https://huggingface.co/code2lora。

- Summary: 本研究探讨了大型语言模型（LLM）辅助写作对神经活动和行为的影响。参与者被分为三组：LLM组、搜索引擎组和纯脑力组（无工具辅助）。每组在相同条件下完成了三次写作任务。在第四次任务中，LLM组的参与者被重新分配到纯脑力组（LLM转纯脑力），而纯脑力组的参与者则被重新分配到LLM组（纯脑力转LLM）。共有54名参与者完成了前三个阶段的任务，其中18人完成了第四阶段的任务。我们通过脑电图（EEG）评估写作过程中的认知负荷，并使用自然语言处理（NLP）技术分析文章内容，同时结合人类教师和AI评分系统对文章进行评分。结果表明，在各组内部，命名实体识别（NER）、n-gram模式和主题本体均表现出较高的同质性。脑电图数据显示，不同组别的大脑连接性存在显著差异：纯脑力组的大脑网络最为强大且分布广泛；搜索引擎组表现出中等程度的参与度；而LLM组的大脑连接性最弱。认知活动随着外部工具使用的增加而逐渐减少。在第四阶段任务中，从LLM转为纯脑力的参与者显示出α波和β波连接性的降低，表明其参与度不足。而从纯脑力转为LLM的参与者则表现出更高的记忆回忆能力以及枕叶-顶叶和额叶区域的激活，这一表现与搜索引擎组相似。此外，自评结果显示，LLM组对文章的“所有权”感最低，而纯脑力组最高。值得注意的是，LLM组的参与者在准确引用自己作品方面也遇到了困难。尽管LLM提供了即时便利，但我们的研究揭示了其可能带来的认知成本。在为期四个月的研究中，LLM组在神经、语言和行为层面的表现始终逊于其他组别。这些结果引发了对长期依赖LLM在教育领域影响的担忧，并强调了深入探究人工智能在学习中角色的重要性。
