# 报告论文分类总结（基于 reports/2026-05-21 ~ 2026-05-28）

> 说明：本总结参考 `conclude_20260519.md` 的结构，对 2026-05-19 之后已生成的日报（`2026-05-21, 2026-05-22, 2026-05-25, 2026-05-26, 2026-05-27, 2026-05-28`）进行归纳。

## 一、总体观察

- 这一阶段最突出的主线是 **Agent 工程化与多智能体系统**：从任务规划、运行时优化、状态回滚、技能自演化到安全护栏，研究重点从“能做”走向“稳定可运营”。
- 第二主线是 **LLM 后训练与推理效率**：围绕 PEFT、数据工程、记忆机制、推理稳定性与 token 级 credit assignment，体现出“更少算力换更高推理质量”的趋势。
- 第三主线是 **量化与时序建模的可执行应用**：组合配置、市场状态识别、波动/利率联合建模、债券指数预测等主题增多，和真实投资流程耦合更紧。
- 同时出现明显的 **治理与可靠性议题升温**：例如对齐篡改（alignment tampering）、算法单一化风险（algorithmic monoculture）、恶意代码请求合规评测等。

## 二、按主题分类摘要

## 1) Agent 系统与运行时基础设施

**代表问题**
- 如何让多 Agent 在复杂任务中保持可扩展、低延迟、可回滚、可审计。
- 如何避免 Agent 系统在共享上下文和协作通信中产生错误传播与安全隐患。

**关键结论（跨论文）**
- Agent 研究从提示策略上移到“系统层”：checkpoint/rollback、JIT 规划调度、通信隔离、技能管理成为核心能力。
- 仅提升单模型能力不足以支撑生产可用性，运行时治理与生命周期安全机制正在成为标准配置。

**代表论文**
- Agent JIT Compilation for Latency-Optimizing Web Agent Planning and Scheduling（2605.21470）
- DeltaBox: Scaling Stateful AI Agents with Millisecond-Level Sandbox Checkpoint/Rollback（2605.22781）
- LCGuard: Latent Communication Guard for Safe KV Sharing in Multi-Agent Systems（2605.22786）
- MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation（2605.27366）
- FinHarness: An Inline Lifecycle Safety Harness for Finance LLM Agents（2605.27333）

## 2) LLM 后训练、推理与记忆机制

**代表问题**
- 如何在参数高效训练框架下平衡稳定性与可塑性。
- 如何改善推理链条中的长期记忆一致性、错误归因与泛化稳健性。

**关键结论（跨论文）**
- 后训练研究在从“是否有效”转向“何时退化、为何退化、如何监控修复”。
- 记忆相关工作从外挂式 memory 转向可持续演化的结构连接与误差可追踪机制。
- RLVR / token credit / 数据选择等细粒度优化路径被反复验证，显示低成本增益空间仍然可观。

**代表论文**
- PEFT-Arena: Understanding Parameter-Efficient Finetuning from a Stability-Plasticity Perspective（2605.28819）
- Skill-Conditioned Gated Self-Distillation for LLM Reasoning（2605.28791）
- Mem-$π$: Adaptive Memory through Learning When and What to Generate（2605.21463）
- MemTrace: Tracing and Attributing Errors in Large Language Model Memory Systems（2605.28732）
- DelTA: Discriminative Token Credit Assignment for Reinforcement Learning from Verifiable Rewards（2605.21467）

## 3) 量化金融与时序建模

**代表问题**
- 如何把 regime 识别、波动建模、组合约束与动态配置整合为可落地流程。
- 如何在多市场/多资产环境中把深度模型预测转化为风险可控的配置决策。

**关键结论（跨论文）**
- “先识别市场状态，再做配置”的两阶段范式更加主流（HMM、RL、时变风险框架结合）。
- 论文主题正从单点预测扩展到端到端投资链路（预测—配置—风险度量）的联合优化。

**代表论文**
- Regime-Based Portfolio Allocation Using Hidden Markov Models and Reinforcement Learning（2605.27848）
- Deep Learning Forecasting of the U.S. Aggregate Bond Index（2605.27977）
- Stochastic Volatility, Jumps, and Rates: A Unified Framework for Option Pricing and Term-Structure Simulation（2605.27945）
- Continuous Timing Signals for Growth-Defensive Style Allocation（2605.20636）
- Falcon-X: A Time Series Foundation Model for Heterogeneous Multivariate Modeling（2605.27286）

## 4) 治理、安全与评测可靠性

**方向概览**
- 对齐安全：RLHF 被利用与“对齐篡改”风险。
- 社会系统影响：招聘场景下算法单一化。
- 模型边界评测：恶意代码请求服从性、多模态一致性与感知脆弱性。

**代表论文**
- Alignment Tampering: How Reinforcement Learning from Human Feedback Is Exploited to Optimize Misaligned Biases（2605.27355）
- Algorithmic Monocultures in Hiring（2605.27371）
- Code as a Weapon: A Consensus-Labeled Prompt Bank for Measuring Coding-Model Compliance with Malicious-Code Requests（2605.28734）
- Lost in Fog: Sensor Perturbations Expose Reasoning Fragility in Driving VLAs（2605.21446）

## 三、与量化高度关联的论文（重点标注）

1. **Regime-Based Portfolio Allocation Using Hidden Markov Models and Reinforcement Learning（2605.27848）**  
   - 主题：市场状态识别 + 资产配置。  
   - 价值：直接对应“择时与仓位切换”问题，适合做策略层实验基线。

2. **Continuous Timing Signals for Growth-Defensive Style Allocation（2605.20636）**  
   - 主题：成长/防御风格轮动信号。  
   - 价值：可用于风格暴露管理与风险匹配，具备组合层可解释性。

3. **Stochastic Volatility, Jumps, and Rates: A Unified Framework...（2605.27945）**  
   - 主题：波动、跳跃、利率的一体化建模。  
   - 价值：对期权定价、压力测试与情景模拟有直接实务意义。

4. **Deep Learning Forecasting of the U.S. Aggregate Bond Index（2605.27977）**  
   - 主题：债券指数预测。  
   - 价值：可作为固收资产配置和宏观择时模块的候选输入。

5. **Falcon-X: A Time Series Foundation Model for Heterogeneous Multivariate Modeling（2605.27286）**  
   - 主题：异构多变量时序基础模型。  
   - 价值：适合跨资产、跨频率数据的统一表示学习。

## 五、可执行后续建议（下一步研究）

- 先做一个“状态驱动配置”最小实验：
  - 基线：固定权重或简单风险平价；
  - 增强：引入 HMM/regime 信号进行动态调仓；
  - 比较：年化收益、最大回撤、换手、交易成本后 IR。
- 并行建立“波动-利率-跳跃”风险情景模块，用于压力测试和仓位上限约束。
- 若资源允许，再引入 Falcon-X 类时序表征作为上游特征，对比传统因子/统计特征增益。
