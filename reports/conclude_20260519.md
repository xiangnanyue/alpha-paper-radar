# 报告论文分类总结（基于 reports/2026-05-05 ~ 2026-05-18）

> 说明：本总结基于 `reports` 中出现的论文条目，并结合 `data/raw/*.jsonl` 内的论文摘要内容进行归纳（共覆盖 227 篇）。

## 一、总体观察

- 过去两周主线非常集中在 **LLM Agent、推理与任务编排**：从单轨 ReAct 到并行搜索、证据图拼装、反思记忆（如 FORGE、Argus）等，核心矛盾是“效果提升 vs 推理成本膨胀”。
- 第二主线是 **训练/系统工程**：包括二阶优化落地、运行时资源编排、模型蒸馏与部署效率，强调可扩展性与成本可控。
- 第三主线是 **治理与评测可靠性**：包括偏见传播、合规监控、榜单与评估方法失真等问题。
- 量化相关论文数量不算最多，但**实务价值密度高**，特别在风险模型增强、组合约束学习、横截面选股表示学习几个方向。

## 二、按主题分类摘要

## 1) LLM Agent 与推理系统

**代表问题**
- 如何把“多次调用模型”转化为稳定收益，而不是 token 堆砌。
- 如何避免并行搜索重复劳动、上下文超限和错误级联。

**关键结论（跨论文）**
- “结构化上下文 + 分工协作”比单纯加长思维链更稳健。
- 多 Agent 并行有效，但需要共享证据结构与调度器，否则边际收益快速递减。
- 反思型 memory 机制在无梯度更新前提下仍可显著改善策略质量，但跨任务泛化仍待验证。

**代表论文**
- Argus: Evidence Assembly for Scalable Deep Research Agents（2605.16217）
- FORGE: Self-Evolving Agent Memory...（2605.16233）
- Context, Reasoning, and Hierarchy...（2605.16205）
- Prospective multi-pathogen disease forecasting using autonomous LLM-guided tree search（2605.16238）

## 2) 模型训练与系统优化

**代表问题**
- 大模型训练中，二阶优化“理论好但工程重”的落地瓶颈如何解。
- 蒸馏后如何保持性能接近 teacher 同时显著降成本。

**关键结论（跨论文）**
- 训练性能上限越来越受系统层编排影响（GPU/CPU/NVMe 协同、异步计算、分布式同步策略）。
- 对于部署侧，离线语义监督可显著提高小模型策略可用性（速度与尺寸双优化）。

**代表论文**
- Runtime-Orchestrated Second-Order Optimization for Scalable LLM Training（2605.16184）
- Offline Semantic Guidance for Efficient Vision-Language-Action Policy Distillation（2605.16241）

## 3) AI 治理、评测与社会影响

**代表问题**
- LLM 介入传播后，平台级偏置是否会在网络中放大。
- 面向规则/法规约束，如何做可执行监控与干预。

**关键结论（跨论文）**
- 偏置并非只体现在人机对话层，还会通过“人-人沟通中介化”产生群体意见漂移。
- 形式化方法（如 LTL 监控）在合规检测上可显著优于纯 LLM 裁判。

**代表论文**
- AI-Mediated Communication Can Steer Collective Opinion（2605.16245）
- Formal Methods Meet LLMs...（2605.16198）
