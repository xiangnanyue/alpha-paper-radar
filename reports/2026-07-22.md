#### 1) Understanding Reasoning from Pretraining to Post-Training Jingyan Shen
- Hotness: **1412** (delta: **+0**)
- Published: 2026-07-17
- Authors: Ang Li, Salman Rahman
- Matched topics: llm_progress
- Matched keywords: llm_progress: reasoning
- BAAI: https://hub.baai.ac.cn/paper/9fe74111-2cbe-47e9-8976-74b343754db3
- Summary: 强化学习（RL）已成为提升大语言模型（LLM）在复杂推理任务上性能的核心手段；然而，当前对 RL 后训练阶段的研究，大多脱离其前置的预训练阶段而孤立进行。由此导致两个基础性问题至今悬而未决：（1）预训练阶段的选择（如模型规模、训练数据）如何影响 RL 计算资源投入所带来的性能增益；（2）RL 究竟对模型本身产生了何种实质性的改变？在标准的大语言模型研究范式下，这些问题难以深入探究：一方面，预训练所用语料库规模庞大且缺乏可控性，致使我们难以将模型行为的变化明确归因于预训练抑或 RL；另一方面，在预训练与 RL 两个阶段同步开展系统性的计算资源规模扫描，其成本高得令人望而却步。为应对上述挑战，我们选取国际象棋作为受控实验平台，以系统考察从预训练到后训练全过程中的推理能力演化机制。我们严格遵循标准 LLM 训练流程：首先，基于人类对弈棋谱，对参数量从 500 万至 10 亿不等的语言模型开展预训练；继而，利用合成生成的推理轨迹对其进行监督微调（SFT）；最后，在具有可验证奖励信号的国际象棋谜题上执行强化学习。借助这一框架，我们发现：在给定 RL 计算预算的前提下，RL 后模型的最终性能可由其预训练损失值较好地预测；同时，RL 奖励曲线的上升斜率大致随预训练所用 token 总量呈线性增长。除规模效应外，我们还发现，RL 并非仅简单地“锐化”监督微调所得策略：在简单谜题上，RL 主要放大了 SFT 策略本已倾向选择的正确走法；而在困难谜题上，RL 则能发掘出那些在 SFT 策略下几乎从未出现的正确走法。为进一步检验上述发现是否具备领域泛化能力，我们另在数学领域文本上训练了一个 10 亿参数的语言模型，结果同样观察到一致的预测模式：预训练时长更久的检查点，不仅在 RL 后取得更高性能，而且在 RL 过程中性能提升速度也更快。综上所述，本研究首次为预训练与强化学习之间的交互机制提供了定量刻画，并构建了一个受控实验平台，从而为系统探索“从预训练到后训练”全链条中推理能力的形成与演化规律奠定了科学基础。

#### 2) DeepLoop: Depth Scaling for Looped Transformers Shuzhen Li
- Hotness: **2732** (delta: **+0**)
- Published: 2026-07-15
- Authors: Yifan Zhang, Jiacheng Guo
- BAAI: https://hub.baai.ac.cn/paper/d61de1ab-5ccf-4144-894a-d710e249c988
- Summary: 循环式Transformer通过将一个紧凑的物理模块堆栈重复应用多轮，来扩展序列计算能力，从而在不增加存储参数量的前提下提升展开后的网络深度。这种参数复用方式改变了残差缩放问题的本质：在非绑定（untied）Transformer中，每个残差分支各自接收并应用独立的参数更新；而在循环式Transformer中，所有重复访问共享同一份参数更新——该更新聚合了各次访问所产生的梯度，并在下一轮线性展开的前向传播中被这些访问再次读取。我们通过一个由“访问对齐系数”$κ_R$控制的一阶微扰界，对这种参数绑定带来的深度效应进行了形式化刻画。当各次访问彼此去相关时，该界可退化为DeepNorm所采用的指数形式；但在更为保守的“强对齐”情形下（即各次访问高度相关），随着循环次数增加而物理深度保持不变，所需残差缩放指数须从$1/4$提升至$1/2$。基于此分析所提出的新型方法——**DeepLoop**，延续Post-LN结构下的DeepNorm架构设计，将残差缩放系数设为$α=(2N)^{1/2}$、归一化缩放系数设为$β=(8N)^{-1/2}$，其中$N$为展开后的总深度。在GPT-2 small与GPT-2 medium规模的GPT风格循环语言模型上，DeepLoop在未发生任何物理模块复用（即无循环）时性能表现中性；一旦启用循环机制、引入递归深度后，则显著降低验证损失，并提升下游任务准确率。上述结果表明：要实现稳定可靠的递归深度，残差缩放策略必须依据参数实际被访问的频次进行建模，而不能仅依赖于名义上的层数计数。

#### 3) TRACE: Turn-level Reward Assignment via Credit Estimation for Long-Horizon Agents Leitian Tao
- Hotness: **260** (delta: **+0**)
- Published: 2026-07-15
- Authors: Baolin Peng, Wenlin Yao
- Matched topics: llm_progress
- Matched keywords: llm_progress: agent
- BAAI: https://hub.baai.ac.cn/paper/68681b97-2517-4e1a-997f-d5cbccec2716
- Summary: 多轮次智能体通过在生成最终答案前与工具进行长时间、多步骤的交互来完成复杂任务，这使得后训练阶段的信用分配成为一项根本性挑战。结果奖励（outcome rewards）虽能为短视野推理提供可靠的监督信号，但当轨迹长度扩展至数十乃至数百次工具调用时，其稀疏性显著增强、方差大幅升高。此外，结果奖励还可能产生误导：一次失败的推理轨迹中，往往包含大量有益的动作——这些动作切实推动智能体向目标靠近，然而仅依赖结果的训练方式却将这些有用动作与最终导致失败的错误动作一并赋予相同的负向优势值（negative advantage）。为此，我们提出 TRACE（基于信用估计的回合级奖励分配方法，Turn-level Reward Assignment via Credit Estimation），一种面向智能体强化学习的稠密型信用分配方法。TRACE 将推理轨迹建模为以工具调用为边界的若干状态转移序列；借助一个冻结的参考模型，获取各状态对应黄金答案（gold answer）的对数概率；再将其转换为对数比形式的状态价值（log-ratio state values）；最后，通过计算相邻状态价值之间的时序差分（Temporal-Difference, TD）变化量，导出每个动作对应的即时奖励。该方法无需额外训练评判器（critic）或人工标注的过程标签（process labels），且其核心的一阶对数比时序差分（one-step log-ratio TD）组件可在冗余的工具调用序列上自然“望远镜式”累积（telescopes）。在长视野复杂搜索任务上，TRACE 仅通过纯强化学习即显著提升了基线模型的工具使用能力，全程无需冷启动式的监督微调阶段、无需智能体专属的中期训练阶段，亦无需依赖实时网络数据进行训练。在封闭网络环境下的 BrowseComp-Plus 基准测试中，TRACE 将 Qwen3-4B 的性能从 7.2 提升至 35.6，将 Qwen3-30B-A3B 的性能从 8.4 提升至 42.6。所习得的搜索行为还能有效迁移到开放网络基准测试中；同时，强化学习训练过程中的学习曲线显示，模型更早实现性能提升，且收敛速度明显加快。

- Summary: 多轮次智能体通过在生成最终答案前与工具进行长时间、多步骤的交互来完成复杂任务，这使得后训练阶段的信用分配成为一项根本性挑战。结果奖励（outcome rewards）虽能为短视野推理提供可靠的监督信号，但当轨迹长度扩展至数十乃至数百次工具调用时，其稀疏性显著增强、方差大幅升高。此外，结果奖励还可能产生误导：一次失败的推理轨迹中，往往包含大量有益的动作——这些动作切实推动智能体向目标靠近，然而仅依赖结果的训练方式却将这些有用动作与最终导致失败的错误动作一并赋予相同的负向优势值（negative advantage）。为此，我们提出 TRACE（基于信用估计的回合级奖励分配方法，Turn-level Reward Assignment via Credit Estimation），一种面向智能体强化学习的稠密型信用分配方法。TRACE 将推理轨迹建模为以工具调用为边界的若干状态转移序列；借助一个冻结的参考模型，获取各状态对应黄金答案（gold answer）的对数概率；再将其转换为对数比形式的状态价值（log-ratio state values）；最后，通过计算相邻状态价值之间的时序差分（Temporal-Difference, TD）变化量，导出每个动作对应的即时奖励。该方法无需额外训练评判器（critic）或人工标注的过程标签（process labels），且其核心的一阶对数比时序差分（one-step log-ratio TD）组件可在冗余的工具调用序列上自然“望远镜式”累积（telescopes）。在长视野复杂搜索任务上，TRACE 仅通过纯强化学习即显著提升了基线模型的工具使用能力，全程无需冷启动式的监督微调阶段、无需智能体专属的中期训练阶段，亦无需依赖实时网络数据进行训练。在封闭网络环境下的 BrowseComp-Plus 基准测试中，TRACE 将 Qwen3-4B 的性能从 7.2 提升至 35.6，将 Qwen3-30B-A3B 的性能从 8.4 提升至 42.6。所习得的搜索行为还能有效迁移到开放网络基准测试中；同时，强化学习训练过程中的学习曲线显示，模型更早实现性能提升，且收敛速度明显加快。
